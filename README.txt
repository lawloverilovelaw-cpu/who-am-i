MUSIC PLAYER - how to put it on GitHub

1. Make a new GitHub repository and upload everything in this folder (index.html, songs.js, music/, images/).
2. Repository Settings > Pages > Source: "Deploy from a branch", branch main, folder / (root). Save.
3. After a minute your player is live at https://YOURNAME.github.io/REPONAME/

Add a song:      put the .mp3 in the music folder, add one line to SONGS in songs.js, upload both.
Add a character: put the picture in the images folder, add one line to CHARACTERS in songs.js.
Keep file names without odd symbols. Each file on GitHub must be under 100 MB.
